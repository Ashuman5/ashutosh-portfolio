# Ashutosh Tiwari — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and resume-based content
- `style.css` — layout, visual theme, responsive styles
- `script.js` — mobile navigation, theme toggle, project filters, form validation

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or install the Live Server extension and choose **Open with Live Server**.
3. Test mobile navigation, theme toggle, project filters, and form validation.

## Contact form note
The contact form currently validates the input in the browser only. It does **not** send email or store messages. See the instructions provided in the accompanying ChatGPT response before connecting a real form service or backend.

## Before publishing
- Verify all resume details and links.
- Add real repository/demo links to projects if available.
- Consider whether you want your phone number on a public website; this version uses email and professional profile links only.
- This site loads Google Fonts from Google Fonts, so those fonts need an internet connection. The page still has system-font fallbacks.
- GitHub Pages can host this static site. It cannot run a server-side backend or safely store private API keys.
